# Hackathon Idea Vault

Discover, explore, and organize hackathon ideas. Built with React + Vite. No backend, no database.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Import the repo into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
